# Audit reports

Bug-hunter (Agent 2) reports may land here as `BUG_AUDIT-YYYY-MM-DD.md`.

- Strip PHI: no resume text, emails, phones, license numbers, or invite tokens.
- Prefer High / Medium / Low sections with path, cause, and suggested fix.
